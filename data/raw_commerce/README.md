# Commerce lifecycle layer (generated)

The nine files in `../raw_olist/` are the real Kaggle Olist dataset, byte-identical
to source. **The six files in this directory are not.** Olist ships no refund,
coupon, return, damage or replacement data, so these tables are generated by
`scripts/generate_commerce_layer.py` and keyed to real Olist `order_id`s,
`product_id`s, purchase timestamps and review scores.

Regenerate with `python3 scripts/generate_commerce_layer.py` (seed `20181017`,
fully deterministic). Verify with `python3 scripts/validate_recoverability.py`.
